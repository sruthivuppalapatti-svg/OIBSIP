# Retail Sales EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset inspection
- Mean, Median, Mode and Standard Deviation
- Monthly sales trends
- Quarterly sales trends
- Customer age-group analysis
- Gender analysis
- Product category analysis
- Revenue by product category
- Correlation heatmap
- Average spending by age group

## Conclusion

The analysis helps understand customer characteristics, sales trends, product category performance and revenue patterns.

## Business Recommendations

1. Focus on product categories that generate higher sales and revenue.
2. Use customer age-group and gender insights for targeted marketing.
3. Monitor monthly and quarterly sales trends for better sales and inventory planning.
